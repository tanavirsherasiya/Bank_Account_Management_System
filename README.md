## 1. Introduction

The Bank Account Management System is a Python-based mini project.
It is designed to perform basic banking operations.
It helps users manage their bank accounts easily.

## 2. Objectives

- To create a simple banking system using Python.
- To manage bank account details.
- To perform basic banking operations.
- To understand Python programming concepts.

## 3. Features

- Create a bank account.
- Deposit money.
- Withdraw money.
- Check account balance.
- Display account details.
